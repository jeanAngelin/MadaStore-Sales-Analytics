# Guide de création Power BI

Power BI Desktop est installé. Le classeur `reports/MadaStore_Sales_Analysis.xlsx` a été ouvert et sa feuille `Clean_Data` (5 993 lignes propres) est chargée dans un rapport local non encore enregistré. Les ventes sont synthétiques. À terminer dans Power BI : vérifier le type date de `order_date`, enregistrer sous `powerbi/MadaStore_Sales_Analytics.pbix`, puis ajouter une page d’aperçu avec cartes de ventes/bénéfice/commandes, ventes par mois, produit et région, et des segments de date, région et catégorie.
